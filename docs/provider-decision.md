# 模型与浏览器决策记录

日期：2026-09-07

## 当前冻结方案

- 目标浏览器：最新版 Chrome 或 Edge。两者均提供摄像头本地预览、Web Speech API 语音识别（可用性取决于系统/网络）和系统语音合成。
- 主业务引擎：本地确定性规则引擎，无调用费用，不发送简历或回答到第三方，可离线演示。
- 在线 LLM：保留适配边界，本原型未默认启用。原因是免费额度、实名/支付要求、数据使用条款和地区网络可用性会变化，不能在未经现场验证时作稳定承诺。
- 降级：语音识别失败时保留文字输入；播报失败时保留文字题目；任何网络故障下继续使用预生成平行问题、规则评价和模板报告。
